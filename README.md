# Customer Support CRM

Customer Support CRM built using FastAPI, SQLite, SQLAlchemy, HTML, CSS and JavaScript.

## Features

- Create Ticket
- Search Ticket
- View Ticket Dashboard
- Close Ticket
- Delete Ticket
- SQLite Database Storage

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript

## Run Project

pip install fastapi uvicorn sqlalchemy

python database.py

python -m uvicorn Api:app --reload
